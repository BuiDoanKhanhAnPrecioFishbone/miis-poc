# Medlingsinstitutet - design system package

Contents:
- `MI_Design_System.pdf` - visual design-system specification.
- `design-tokens.json` - machine-readable tokens.
- `mi-design-system.css` - CSS variables and baseline components.
- `tailwind-mi-theme.ts` - Tailwind theme fragment.
- `LOVABLE_IMPLEMENTATION_PROMPT.md` - prompt for updating an existing Lovable.dev app.

Important:
The palette is an extended implementation palette derived from the visible Medlingsinstitutet identity and recent publication artwork. It should be validated against the customer's original brand files before production sign-off.

The exact current MI font family could not be reliably verified from public indexed material, so this package deliberately uses safe system fallbacks rather than inventing a brand-font claim.

Logo:
The official logo includes a protected Swedish state emblem. Do not recreate it. Insert the customer's official master logo asset unchanged into the app and PDF/brand repository. The design system defines placements and variants but does not fabricate new logo artwork.
