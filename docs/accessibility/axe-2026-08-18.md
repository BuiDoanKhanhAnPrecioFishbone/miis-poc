## Points the new step had to get right

| Check | How |
|---|---|
| The file input is reachable by keyboard (2.1.1) | A real `<input type="file">`, visually hidden but focusable, with a `<label>` as the visible 48px control. Drag-and-drop is an enhancement, never the only route in. |
| The label shows focus | `peer-focus-visible` on the label mirrors the input's focus, using the same `--mi-focus` outline as every other control. |
| Progress is announced (4.1.3) | One `aria-live="polite"` line that names the current position — *"3 av 4 steg klara"* — rather than four separate live regions competing. |
| Stage state is not colour alone (1.4.1) | Every stage row carries the state word beside the mark: *Klart · Pågår · Återstår*, the same vocabulary as the stepper. |
| Focus after an asynchronous change (2.4.3) | When the pipeline finishes, the form replaces the upload panel. Focus moves to the review panel rather than being left on a control that no longer exists. |
| The stepper tells the truth | `aria-current="step"` follows real state through all four positions: step 1 before a file, step 2 during the pipeline, step 3 at the approval, step 4 once approved. |
| Refusal is not colour alone | The rejected-format message is a `Callout tone="error"` — left rule, icon and label word — and names the file and the accepted formats. |
